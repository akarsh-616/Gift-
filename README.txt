BESTIE MIXED HINTS WEBSITE
============================

Files:
- index.html
- style.css
- script.js
- assets/last-image.jpg

LOCAL TEST:
1. Open this folder in VS Code.
2. Install "Live Server" extension if you want.
3. Right-click index.html -> Open with Live Server.
4. Test the buttons and final image.

GITHUB:
1. Create a PUBLIC GitHub repository.
2. Upload all files/folders, not the ZIP.
3. Keep this exact structure:
   index.html
   style.css
   script.js
   assets/last-image.jpg
4. Settings -> Pages
5. Source: Deploy from a branch
6. Branch: main
7. Folder: / (root)
8. Save.
9. Open the generated github.io link.

IMPORTANT:
Do not rename index.html.
Do not move last-image.jpg out of assets.
